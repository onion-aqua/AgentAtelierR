# AgentAtelierR 1.0.4.8 · 安卓构建 64

## 更新内容

- 更新 9 套莱莎皮肤和配套动画，支持新版 Spine 4.3 资源。
- 莱莎会随台词变化眼神和表情。问候、思考和打趣时可配合自然手势，晃脚等动作也有更多变化。
- 多句回复按朗读进度切换表情。关闭语音或合成失败时，每句表情按阅读时长停留。
- 经典和气泡聊天框都会在新回复前显示「最新消息」分隔线。

## 使用方法

在「设置 → 关于 → 版本与更新」点击「检查更新」，或下载构建 64 的安卓 APK 覆盖安装。已安装 1.0.4.8 构建 63 的用户也可以直接升级。新版皮肤需要随本次 APK 安装的动画运行时，按系统提示完成安装后即可在主界面体验。
