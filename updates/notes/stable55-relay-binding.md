# AgentAtelierR 1.0.4.1 · PC Agent 联动更新

## 更新内容

- PC Agent 支持自选 HTTPS 云中继，已有绑定继续连接原服务器。
- 支持 PC 选择 1、3、7 天绑定期限，新版二维码扫码后可直接绑定。
- 解绑后立即清除本机绑定和缓存；断网时保留安全撤销记录，联网后自动重试。
- 修复网络等待期间设置、扫码和解绑不可用，以及晚到响应恢复旧绑定的问题。
- 保留已有壁纸和资源更新。

## 使用方法

在应用更新提示或「设置 → 应用更新」中下载更新，并按 Android 提示确认安装。

进入「PC Agent 联动 → 云中继设置」选择默认服务或填写自己的 HTTPS 地址，再扫描新版 PC 插件生成的二维码并确认信任。绑定期限由 PC 创建二维码时选择；旧版二维码仍可能要求 PC 确认。

## 注意事项

- 本次包含程序代码更新，需要系统确认安装；不会清除存档和聊天记录。
- 断网解绑会先完成本机删除，服务器撤销需等待网络恢复。
- 后台远程推送尚未启用，锁屏提醒不能保证送达。
