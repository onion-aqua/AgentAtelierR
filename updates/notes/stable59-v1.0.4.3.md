# AgentAtelierR 1.0.4.3

## 更新内容

- 修复开启液态玻璃后设置页面卡顿：复用背景模糊，取消重复的全屏折射采样，触摸流光仅重绘装饰层。

- 新增人格倾向试用：11 种预设、自定义人格、可触摸调整的参数图谱，以及配置导入导出。预设与自定义人格会作为持续扮演要求应用到后续对话。
- 云端 TTS 支持最多两路并行准备、按原顺序播放，减少段落等待；覆盖聊天、持续 ASMR 和现有通话语音服务。
- 虚拟电话支持 Fish Audio MCP，音色和模型复用语音设置；改进说话打断、回复后恢复收音和字幕语言处理。
- 新增冷启动睡眠与点击叫醒演出，优化启动加载。
- 优化设置分类、输入框、液态玻璃及明暗主题显示，改善虚拟手机状态栏过渡，去掉角色切换按钮中间的竖线。
- 修复旧记忆编号导致整理失败的问题，增加兼容整理与用户提示。
- 商店新增“誓约之戒”，售价 4999 关系点数，购买后放入“珍贵的东西”。

## 使用方法

- Android 用户可在更新提示中选择更新，或前往设置中的应用更新入口；下载后按系统提示确认安装，也可从本页下载 APK 覆盖安装。
- 人格设置：虚拟手机 → 设置 → 角色与世界 → 人格倾向（试用）。新建或选中档案，调整图谱，开启人格倾向并保存；关闭后恢复原有表达。编写说明见仓库 `docs/personality_authoring_guide.md`。
- 云端 TTS 的双路准备自动启用，播放顺序不变。通话选择 Fish MCP 时，先在语音设置完成 OAuth 连接和工具读取，再拨打电话。
- 冷启动后点击“叫醒莱莎”，唤醒演出结束即可聊天。

## 注意事项

- 这是修复后的构建 55，替代已撤回的构建 54。已安装旧包的用户同样可覆盖更新。

- 本次为 Android 程序更新，需要系统确认安装；请覆盖安装，卸载可能删除本地存档和设置。重要数据建议先导出备份。
- 人格表现受模型能力影响；手动参数、语言设置和明确拒绝仍优先。
- 本地 CosyVoice 保留单路生成。云端限流后会降低并发；已提交的语音请求即使被打断仍可能计费，结果未知时不自动重发。
- 实时电话仅支持 Android 前台使用；通话目前支持 Fish API/MCP。免提插话效果受设备回声消除能力影响。
- 在物品页确认丢失誓约之戒会扣除 500 心情，并限制购买和好券；心情恢复到 −250 或更高后解除。
- 本页提供 Android 1.0.4.3；Windows 用户请继续使用 1.0.4.2 的 Windows 完整包。
