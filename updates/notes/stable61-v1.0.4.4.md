# AgentAtelierR 1.0.4.4

## 更新内容

- 主聊天界面新增语音通话入口，复用现有语音识别、TTS 和通话配置。
- 更新莱莎内置普通音色；ASMR 按模型选择音色：`s2-pro`、`s2.1-pro`、`s2.1-pro-free` 使用原专用 ASMR 音色，`drama-3` 使用新的内置音色。
- 优化整段耳语标签及呼吸、喘息标签清理，语音情感程度默认设为最低。
- Fish Audio MCP 支持启动后、返回前台及使用前自动恢复已有连接，减少反复手动连接。
- 音色 ID 输入框隐藏已保存内容，支持填写替换、留空保留和恢复默认；保留用户在新版中设置的自定义音色。

## 使用方法

- 在应用更新提示中点击更新，下载后按 Android 系统提示确认安装；也可下载本页 APK 覆盖安装。
- 开启设置中的“显示麦克风按钮”，在通话设置中准备好语音识别模型，再点击主聊天输入栏的麦克风开始通话。
- 在语音设置中选择 Fish Audio API 或 MCP 及模型，切换 ASMR 模式后重新生成语音。播放历史音频仍使用生成时的音色。
- MCP 首次使用需完成 OAuth 授权；已有有效授权会自动恢复连接。手动断开后，重新点击连接即可恢复。

## 注意事项

- 本次提供 Android 更新，覆盖安装保留本地存档；卸载可能删除本地数据，重要存档建议先导出备份。
- 首次从旧版升级会重置一次旧远程自定义音色；需要时重新填写并保存，后续升级保留新版自定义配置。
- MCP 与 API 的计费独立，模型权益以服务端为准。语音生成可能消耗积分或余额，已提交请求不会因播放被打断而自动撤销。
- 各模型的耳语表现不同，音色调整只影响重新生成的语音。
