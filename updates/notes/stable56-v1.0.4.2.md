# AgentAtelierR 1.0.4.2

## 更新内容

- 虚拟手机新增莱莎、科洛蒂娅的前台语音通话，通话记录和记忆跟随存档。
- 科洛蒂娅的通话语言跟随莱莎主语言设置，CC 字幕译文跟随主翻译语言。
- 支持说话打断角色回复，同时停止旧语音和待播内容；增加回声消除与回放过滤。
- 电话设置支持下载本地识别模型，自动校验、解压和填入配置，保留手动导入。
- 更新东方旗袍 r3，新增万圣节女巫服装及预览封面，资源采用加密打包。
- 修复虚拟电话把自身音频焦点变化误判为系统来电的问题。

## 使用方法

在应用更新提示或“设置 → 应用更新”中下载，并按 Android 提示确认安装。

首次通话：打开“虚拟手机 → 电话 → 右上角设置”，点击“下载并安装本地模型”，完成后点击“保存”。在 AI 接口和 Fish Audio REST 设置中填写现有 LLM 配置与 API Key，再选择莱莎或科洛蒂娅拨打；科洛蒂娅可使用内置音色。

通话中可直接说话打断，也可点击“打断”；CC 按钮控制字幕显示。模型下载优先查询 Gitee，未提供模型附件或下载失败时自动回退官方 GitHub。

## 注意事项

- 本次包含程序代码更新，需要 Android 确认安装，保留存档和聊天记录。
- 实时电话目前仅支持 Android 前台使用；进入后台、系统通话抢占或切换存档会结束通话。
- 麦克风原始录音只用于本地识别；识别文字、LLM 回复和字幕翻译产生正常服务用量。通话语音需要 Fish REST API Key，MCP OAuth 无法替代。
- 免提下的插话效果受手机回声消除能力、距离和音量影响，建议使用耳机。
- 本地识别模型约 156 MB。当前 Gitee 尚无模型附件，将回退官方 GitHub；下载失败时可手动导入模型。
