# Ryza Chat Demo 更新日志

## 2026-09-04

### 对话显示

- 将旁白从莱莎的消息区域中完全分离。
- 旁白使用独立的 `≡` 标识，不再显示莱莎头像或“莱莎”名称。
- 保留旁白、莱莎台词和译文在模型原始输出中的先后顺序。
- 莱莎台词与对应译文继续显示在同一个角色消息块中，并使用横线分隔。
- 对话记录弹层同步使用新的旁白分离布局。
- “显示原始输出”开启时仍展示未经清理和重排的完整 LLM 输出。

### 角色互动

- 点击 UI 和莱莎身体以外的场景区域时，莱莎会将瞳孔转向触摸位置。
- 注视方向使用 Spine 眼神控制骨骼驱动，并限制最大偏移幅度。
- 注视保持短暂时间后平滑回到默认位置，不影响身体点击动作与双指镜头手势。

### 地图与场景

- 地图区域、地区和地点名称跟随界面语言切换。
- 补齐 163 个地图节点的中文和英文名称，日文继续使用地图层级资源中的原名。
- 大地图标题、区域选择器、地标、小地图节点、底栏和旅行提示统一使用本地化名称。
- 修正小地图地点坐标投影，并保留原始地区中心与地点偏移映射。
- 聊天场景的背景音乐和环境音根据当前地图地点选择对应资源；没有映射时使用安全回退。
