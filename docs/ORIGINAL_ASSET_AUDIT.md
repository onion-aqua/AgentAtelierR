# 原版资源与 Demo 接入清单

## 本地 APK 资源结论

- 原版 `assets/flutter_assets/assets` 共 3609 个文件，561.7 MB。
- APK 内只有两套可运行的角色 Spine 包：
  - `crf_skn_002_0001_01`：普通坐姿。
  - `crf_skn_002_0001_99`：莱莎 3 常服站姿。
- 原版代码包含皮肤下载、商店、订阅解锁和所有权同步模块，但其他服装模型不在 APK 内，属于服务端资源，无法从当前文件恢复。

## 原版代码边界

当前目录是 APK 解包结果，不包含可编辑的原始 Dart 源码。可恢复的信息来自 AOT `libapp.so` 符号、资源清单和 gesture 配置。已确认但不按此前 Demo 需求复刻的模块包括：账号登录、云同步、皮肤购买、订阅、公告、应用更新和发布流程。
