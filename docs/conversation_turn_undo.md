# 对话、状态与时间回退

主聊天的回退按钮会撤销最后一条用户消息及之后的回复，并恢复发送该消息前的：

- 心情、精力、亲近感、好奇心及状态档位、情绪、原因与结算记录。
- 剧情日期、时分、饱食度、时间结算记录、场景时段和时间模式。
- 对话次数和原有对话情绪；撤销当轮对话获得的 1 点关系点，保留已有购买扣款。

自动续聊归入最近一轮用户消息，一并回退。回退后原用户输入回填到输入栏，
可以修改后重新发送。该轮未完成的状态、时间等异步结果会失效，避免撤回后再次加分或推进时间。
失败回复也在同一次回退中删除。

发送前的小快照随用户消息写入应用本地数据、角色会话、存档槽位和 JSON 备份。
当前保留的历史消息各自有快照，支持连续多次回退；新存档和清空对话不会继承旧快照。
不将回退快照发送给 LLM。

旧版本对话没有发送前快照，无法准确恢复过去的状态和时间。它们仍可回退文字，
当前数值及时间保持不变，界面会说明此限制。损坏或未知版本的快照同样处理，不阻止读取存档。

此操作针对对话状态和时间，不是完整存档回滚；背包物品、已经执行的商城购买、
每日领取记录、NPC 联系人和长期记忆整理沿用各自原有逻辑。需要整体恢复时使用存档。
如果对话后使用了道具或确认丢失誓约之戒，此前的人物状态快照会失效，
回退这些旧轮次时只恢复对话和时间，并明确提示保留当前人物数值，避免清除道具效果或丢失惩罚。

验证：新增 16 项控制器回归和 2 项实际聊天界面测试，覆盖连续回退、跨日饥饿与休息、
迟到规划、重启、存档、导入导出、角色隔离及道具边界。
全量测试 2682 项通过、78 项跳过；全项目静态检查通过。功能开发阶段未构建或发布；随后已在测试机覆盖安装验证。本次正式发布记录以 1.0.4.5 版本及 stable 渠道为准。
