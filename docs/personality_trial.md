# 人格倾向试用说明

入口：**虚拟手机 → 设置 → 角色与世界 → 人格倾向（试用）**。

自定义风格、参数、规则与 JSON 示例见[人格倾向编写指南](personality_authoring_guide.md)。2026-10-22 的表达修复已覆盖全部 11 种预设，已有档案无需重建；具体诊断见[预设表现偏弱修复记录](personality_effect_fix_2026-10-22.md)。

1. 展开「预设与配置」，选择一个预设，点击「从预设新建」。旧档案仍保留。
2. 在图谱的「坐标／基础／关系／表现」四组中直接编辑。拖动坐标圆点调整两条−100至100轴；拖动雷达节点或轴线调整对应的0至100参数，名称和数值实时更新。节点重合在中心时，先点选图例再向外拖动；PC也可用鼠标拖动。参数滑条已移除，人物身份和世界书继续使用原有配置。
3. 在「动机与内在矛盾」编辑动机、规则、情境和优先级。关键词、情绪及亲近感条件都满足时才触发；同优先级按列表顺序。
4. 「情境测试」只执行本地解释器，显示触发原因、动机、行为约束和示意回复，不调用 API，也不会写入记忆、心情或关系。它会临时模拟启用草稿，不改变总开关。
5. 打开「启用人格倾向」并点击底部「保存」，下一轮实际对话使用该档案。页面有未保存修改时，返回会询问是否放弃。
6. 想恢复原本体验，关闭开关并保存。已验证关闭后的主提示词与原链路相同；人格档案仍保留，方便下次比较。

## 参数与规则

内置11预设：元气冒险家、温柔守护者、傲娇、隐忍病娇、外放病娇、腹黑、慢热型、雌小鬼、冷静理性型、姐姐型引导者、笨拙真诚型。坐标与198项具名参数来自提供的部署文档。

两个坐标范围为−100至100；18人格参数、6表现强度范围为0至100。它们是虚构角色的行为调节项，不是游戏当前心情数值。整体显著程度为0时不注入人格效果。

每轮最多选3条规则、2条动机，人格对话区块不超过1200字符；按当前场景选择相关行为参数，不整表发送数值。表情、动作、语音可独立关闭。演出仍受已生成台词、当前情绪、姿态及真实可播放资源约束，不新增虚构动作ID或服务商参数。持续ASMR及传统语音演出也会使用启用的语音偏好，其语言、语音模式和标签设置优先。

## 保存与导入导出

人格按角色独立保存于SharedPreferences：`personality_configuration_v1.<characterId>`。读游戏存档不会覆盖它；完整本地备份包含当前角色的人格配置，明确导入完整备份时恢复。关闭或清除临时心情不会修改人格基线，LLM也没有写入人格的工具。

配置管理支持JSON文件和复制/粘贴，导入先校验再替换草稿，保存后才生效。当前格式为schemaVersion 1，最多24档案、每类24规则；未来版本、非法类型/数值、重复编号及其他角色配置会拒绝。未知顶层字段忽略，未知参数字段拒绝。没有已发布旧人格格式，因此不会猜测迁移未知版本。损坏的本地数据暂时回退关闭状态，保留原始内容，直至用户明确保存有效配置。

## 验证边界

领域、编辑器、存储与演出适配有自动化测试；包含开关恢复、JSON往返、角色隔离、旧存档兼容、非法动作回退、窄屏与双倍字号、保存失败和草稿保护。测试输出见`build/personality-*.log`。

真实角色的表达差异仍取决于所选LLM。初次部署只使用本地示意；随后应用户要求，已在模拟器提交10轮真实聊天，完成开关对照及修复复验，见`docs/personality_chat_test_2026-10-22.md`。TTS保持关闭。Android试用使用项目加密构建脚本；Windows共用这套Dart源码，桌面运行和平台文件选择器需要各自实机确认。原始文档副本为`docs/personality_trial_spec.md`，审计记录为`docs/personality_trial_audit.md`。
