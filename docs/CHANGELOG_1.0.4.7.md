## 更新内容

- 新增气泡聊天样式，支持头像、角色名、原文与译文分隔，旁白使用居中字幕。
- 长按气泡可回退对话、重播或重新生成语音，以及选择文字与语音进行收藏；建议回复和继续对话移至输入栏右侧加号。
- 气泡和长按菜单增加轻量液态玻璃、高光及触摸反馈；滚动时暂停气泡模糊，减少绘制开销。
- 关闭玻璃后，气泡、输入框和音频进度条跟随主题色与明暗模式，修复底部控件残留绿色的问题。
- 改善旁白在复杂背景上的清晰度，补齐预览中的左上角隐藏／恢复 UI 按钮。

## 使用方法

在「设置 → 界面与场景」开启「聊天框样式」即可使用气泡聊天；「液态玻璃对话框」控制玻璃效果。长按气泡打开操作菜单，输入栏右侧加号提供附件、建议回复和继续对话。

## 注意事项

本次为 Android 更新。代码更新需要按 Android 提示确认安装；升级前可在「数据管理」备份存档。若设备开启玻璃后滚动不流畅，可关闭玻璃，继续使用跟随主题配色的气泡界面。
