# AgentAtelierR 1.0.4.4

## 更新内容

- Fish Audio 普通语音和 ASMR 默认语速调整为 0.9 倍；MCP 新增语速设置，服务不支持语速参数时在本地处理并保持音高。
- 角色资源首次解密后保存在应用私有目录，后续启动复用缓存；减少热更新检查中的重复解密。
- 闹钟新增应用内和 Android 锁屏停止界面，支持多个闹钟及停止失败重试。
- PC 联动支持 v2 加密配对二维码，继续兼容旧版配对数据。
- 保留主界面语音通话、MCP 自动重连及按模型适配的 ASMR 音色。

## 使用方法

- 在应用更新提示中下载并按 Android 系统提示安装，也可下载本页 APK 覆盖安装。
- 在语音设置中保存所需语速，再生成普通语音或 ASMR；已有历史音频保持原语速。
- 闹钟响起时点击“停止闹钟”；多个闹钟同时响铃时可停止全部。
- 配对新版 Harness 时扫描或粘贴新二维码，核对后确认绑定；旧二维码仍可使用。

## 注意事项

- 覆盖安装保留存档和聊天记录。首次打开服装仍需生成缓存，资源未变化时后续升级可复用。
- 二维码采用公开兼容密钥，仅隐藏普通扫码工具直接读取的内容，不替代配对鉴权；请勿外传二维码。
- MCP 和 API 计费独立；本地语速处理不会额外生成语音。系统通知及锁屏显示仍受手机权限和厂商设置影响。
