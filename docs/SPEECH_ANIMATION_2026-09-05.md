# 语音与角色动作接入记录

## 原始资源依据

检查了外层 `assets/flutter_assets/assets/spine/crf_chr_002/` 下的
`crf_skn_002_0001_01` 与 `crf_skn_002_0001_99` 的 `_gesture.json`。
坐姿包含 140 个组合动作，站姿包含 53 个；两份文件均有 98 个 DriverDefs。
这些是资源配置证据，不代表已还原原应用编译后的全部动画实现。

| 配置 | 当前用途 |
| --- | --- |
| rigConfig.aimSlots | 定位头、身体和眼睛方向控制骨骼 |
| rigConfig.rollSlots | 定位歪头和身体侧倾控制骨骼 |
| emotionalGesture.DriverDefs[].Spec | 读取情绪动作的 yaw、pitch、roll、过渡与停留范围 |
| Spec.followers | 身体跟随比例，以及以平滑响应近似的延迟跟随 |
| EmotionProfilesV4 / MotionGroups | 沿用当前按情绪权重和姿势兼容性筛选组合动作的逻辑 |
| projectConfig.lipSyncClosure | 参考原有快速张嘴、较慢闭嘴及短暂闭合的设计 |

## 本次行为

- 新增 `character_speech_driver.dart`，运行时读取已安装服装的动作配置，优先选择对应情绪的 normal 驱动，使用平滑插值切换目标。
- 待机也有低强度头部细节；说话时随语音能量提高表现幅度，并保留点头节奏。
- TTS 口型逐帧采样 WAV 包络，播放器进度之间最多外推 250 毫秒，避免进度事件稀疏导致嘴型长时间不变。
- 有声能量上升沿触发兼容当前姿势的组合动作，间隔至少 2.4 秒，并避让刚播放的语义动作。
- 说话和点击互动期间暂停自动大姿势切换；点击动作优先，触摸视线优先于自动眼神。
- 每帧先恢复上一次程序偏移前的骨骼局部值，再应用动画和新的偏移，防止累计旋转或横向漂移。
- 语音结束后的口型关闭，身体附加动作平滑降低到待机强度。

## 验证与限制

- 73 项 Flutter 测试通过，静态检查通过。
- 新测试采用自建的最小配置，覆盖情绪过渡、跟随、持续采样边界和音频结束。
- 压缩音频未实时解码成 PCM，无法获得 WAV 包络时使用模拟开合及定时动作，不声称实现音素级对口型。
- 驱动参数到骨骼局部坐标的幅度是本项目的有界适配，需要真机播放 TTS 判断最终观感。
- 原版资源继续只保存在本地；本说明不包含骨骼、纹理、音频或完整动作配置。
