# 人体状态页与唤醒动作调整

入口：主界面 → 虚拟手机 → 角色状态。

状态页改为角色概览、人体细线标注、选中项目详情、最近变化、场景与角色档案。六个标记连接好奇心、心情、亲近感、饱食度、精力和当前姿态。数据来自当前人物及存档，回退对话、读档或切换人物后同步刷新，没有新增部位伤病或独立体力规则。关闭剧情时钟时饱食度显示为“—”。

人体图使用现有加密常服站姿模型生成的莱莎完整剪影，保留兔耳、发型、手臂、双腿与长靴。进入状态页时生成一次透明静态图，保留在内存中；不切换聊天中的皮肤，不额外保存解密素材。标记锚点与剪影使用同一等比变换；文字按实际高度排布。手机纵向排布，宽屏分为图形和信息两栏。支持中、英、日界面、深浅色、玻璃开关与放大字体，没有新增持续动画或嵌套背景模糊。

## 身体敏感度

「部位敏感度」页签显示头部、胸部、腹部、左臂、右臂、手部、腿部、腰部及私处九项独立数值。范围 0–100，默认 50。初始为只读，不显示数值调整滑条或手动解锁按钮。

连续点击页面标题「角色状态」10 次，才开放本次页面的数值编辑。相邻点击间隔不超过 1.5 秒；点击其他区域或滚动会重新计数。开放后可在所选部位的详情滑条手动调整，松手时保存，且不会修改其他部位。心情、精力等原有概览继续只读。退出状态页、读档、回退对话、切换人物或应用进入后台后重新锁定，编辑权限不写入存档，旧档也不会恢复编辑权限。正常触摸变化及「随触摸变化」偏好开关不受编辑锁影响。

新增的私处初始显示「未解锁」，不显示隐藏数值或调整滑条。只有主动点击人物的真实对应区域，或先开启本次数值编辑后在该项详情点击「主动解锁」，才开放数值；仅选择图中标记、拖动擦过、模型生成台词和直接设置数字都不解锁。部位的解锁状态随人物及存档保存，与临时数值编辑权限分别管理；旧 v1 八部位数据原值保留，新部位仍锁定。触摸增长关闭时仍可主动解锁，数值保持 50。衣物、手臂或其他前景遮挡对应区域时，不穿透命中。

默认启用「随触摸变化」：触摸命中可见身体部件后，对应部位增加 1，同一部位每 10 秒最多增加一次，100 封顶。可关闭自动增长。手腿等部位通过实际不透明贴图命中识别，已有物理晃动强度及轨道保持原逻辑。暂不将这些数值交给 LLM 自动改写，也不改变现有语音选择。

敏感度和增长开关分别随人物、存档、新存档、重启及导入导出保存，旧档没有字段时补齐默认值。回退对话不会抹掉该轮后实际发生的手动调整或触摸；旧快照没有敏感度字段时保留当前值。

## 状态影响互动表达

主聊天（含兼容与独立演出模式）、主角实时电话、持续 ASMR 共用当前人物的状态事实与表达规则。心情调节情绪用词，精力调节句长与节奏，亲近感调节称呼与距离，好奇心调节探索与追问倾向，饱食度及剧情时间调节合适场景下的补给、休息表达。关系点数作为可消费资源参与活动、礼物话题，不能替代亲近感。

已解锁敏感度只在对应部位的互动语境中影响注意和反应细腻程度，不会令普通聊天自动转入身体话题。未解锁部位仅传递锁定标记，不向模型传隐藏值；模型无权修改或解锁数值。状态调节当下表现，人格预设仍决定基础口吻，语言和用户互动边界继续生效。低心情不会被高敏感度或高亲近感自动改成开心。

表情及语音规划器收到同一份已过滤的状态事实，保持台词、表情和声音一致；不新增动作指令或改写台词。NPC 私信和 NPC 电话不接收主角的敏感度，避免人物资料混用。验证采用本地请求捕获与解析测试，未额外请求付费 LLM；实际措辞的变化幅度仍取决于所用模型。

## 唤醒修复

| 内置皮肤 | 当前唤醒方式 |
| --- | --- |
| 常服·坐姿 | 点击部位反馈，三种伸展变化，哈欠、泪光、睁眼 |
| 常服·站姿 | 点击部位反馈，哈欠、泪光、睁眼；不借用坐姿伸展 |
| 夏日泳装·黄色 | 三种伸展变化及点击反馈 |
| 夏日泳装·黑色 | 三种伸展变化及点击反馈 |
| 休闲 T 恤 | 点击反馈、哈欠、泪光、睁眼；停用袖子不跟随的抬臂伸展 |
| 夏日泳装·蓝白短裤 | 三种伸展变化及点击反馈 |
| 东方旗袍·紫色 | 三种伸展变化及点击反馈 |
| 万圣节女巫 | 点击反馈、哈欠、泪光、睁眼；资源没有对应伸展时安全降级 |

伸展仅用于兼容的自然坐姿和基础动作。盘腿保留腿部姿态，临时释放可能覆盖点击动作的手臂休息层，结束后恢复手位。不兼容的基础姿态不强行插入伸展。点击角色时使用命中部位的真实触摸动画；点击叫醒按钮时使用可用的头部反馈变化。不存在的动画不会传给原生运行时。

确认修复的视觉问题：休闲 T 恤原先的 B12 伸展会抬起裸上臂，而衣袖仍留在原位，导致手臂与袖子脱节。此次采用停用不兼容动作的方式修复，没有修改或重新分发原始贴图、骨架。

另修复万圣节皮肤的基础姿态目录：原先复制了常服的 20 项列表，含本皮肤缺失的动画；现按实际骨架只列出 001、002、003、005、007、009 六项。原生测试逐套核对所有公开的闲置动作确实存在，避免界面提供无效资源选项。

## 验证范围

- 8 套真实加密皮肤及预览通过认证、索引哈希、文件映射检查；解密后的图集、骨架、贴图及修复动作配置与各自源资源一致。
- 8 套加密包经应用实际 `ProtectedCharacterAssetBundle` 路径，在 Windows 原生 Spine 运行时加载并运行 120 帧，通过检查；解密素材未写出到审计目录。
- 原生唤醒渲染覆盖每套皮肤的三种选择、七个点击部位、阶段切换、结束清理与不兼容姿态检查。可视化用于人工检查，数值测试不能自动证明完全没有穿模。
- 状态页测试覆盖数值、负心情、时钟关闭、标记交互、动态刷新、三语言、320/390/横屏/桌面、深浅色、玻璃开关、放大字体及标记边界。
- 实际聊天页 → 虚拟手机 → 状态页集成测试验证状态与时间结算后刷新，并在回退时恢复显示。
