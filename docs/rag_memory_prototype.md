# 本地混合 RAG 记忆试用版

入口：设置 → 数据管理 → 长期记忆 →「本地 RAG 记忆 · 试用」。默认开启，可随时关闭对比；「测试回忆」只在本机查询，不生成聊天或语音。

本版保留 Horae 结构化台账、最近摘要与当前状态规则，增加完整成功对话归档、BM25 关键词和本地多语言神经向量的混合检索。主聊天每轮自动准备证据，Agent 模式也会直接获得相关回忆；主角电话和持续 ASMR 复用相同流程，NPC 私信不读取主角归档。原始对话中的问题、愿望或角色猜测不被自动确认为事实，当前状态优先于旧事件。

## 保存与迁移

- 聊天窗口仍显示最近 60 条，成功轮次的用户原话和助手原文另外归档，不因窗口滚动丢失。
- 归档随当前人物、存档与备份导入导出。向量索引仅作为可重建缓存，读档、换人物和撤回会使旧查询失效。
- 旧版只迁移设备上仍存在的成功对话及记忆，不能恢复过去已被窗口裁掉且没有其他记录的原文。
- 关闭长期记忆或试用开关时，不继续新增归档或检索；已有归档保留。正在执行的模型初始化或当前推理批次会完成，不再处理下一批。
- 回退同时撤销该轮归档及有关来源台账。删除带来源编号的台账条目会撤销相应原始证据；没有来源编号的旧摘要无法可靠反推全部原文，不能把删除摘要等同于删除所有原始对话。
- 清空聊天记录会清除完整对话归档；选择保留长期记忆时，独立台账继续保留。请先导出需要保留的存档。

## 本地模型与性能边界

使用公开的 DistilUSE 多语言量化 ONNX 模型，内置模型约 137 MB，输出 512 维归一化向量。CPU 推理在后台 isolate 完成，最多 2 个线程；仅首次使用时加载，不加入冷启动必等任务。模型和词表来源、许可与校验值见 [模型说明](third_party/rag-memory-model.md)。不会发送原文到 Embedding API。

每轮等待语义准备的默认上限为 3 秒，超时先使用关键词检索；仍有效的后台索引会供后续查询复用。每片保留说话者及来源，片段不超过 96 字符，长句带 20 字符重叠。最多选择 6 条证据，原文预算为 2400 字符（兼容模式为 1800）；这些是证据文本预算，不是整份提示词的 token 上限。

向量缓存目前最多 4096 片，不是永久向量数据库。超过时优先本轮关键词候选和较近片段，所有原文仍参与关键词检索，避免缓存反复淘汰和重算。首次大档案索引、较弱设备的推理，以及大量历史的检索覆盖仍属试用观察范围。

## 验证解释

测试题使用独立的合成对话，不修改用户存档，也不调用真实收费 LLM/TTS。

- 检索器单测包括 60 条中、英、日关键词回忆题，以及向量输入、预算、去重、删除和无关候选拒绝。
- 真实模型的 50 条改述及跨语言问题，纯向量排名 Top1 为 48/50，Top3 为 50/50。
- 生产混合检索器启用保守相关性门槛后，实际返回的正确候选为 39/50；不能把无门槛排名结果称为实际召回率。
- 30 条未记录的问题中，21 条无返回，9 条召回相关背景。相关背景不能证明未记录的细节；生成模型仍须依据证据回答“不知道”，这些数字不代表实际对话回答的正确率。

Android 36.1 x86_64 模拟器已使用加密 release 验收：

- 真实本地模型完成 90 段测试文本的 512 维推理；50 条正例中混合检索 Top1/Top3 均为 39，纯关键词 Top3 为 20。30 条未记录问题中 21 条无返回。
- 36 轮对话超过可见窗口后，最早的暗号仍能由控制器召回并自动进入 Agent 提示词；撤回、读入旧存档、关闭和重新开启试用的隔离检查均通过。
- 首次模型准备与 90 段推理合计约 3.7 秒，整套本地验收约 4.4 秒。这是桌面宿主的 x86_64 模拟器结果，不能当作 ARM 手机速度。
- 修复了后台 isolate 请求 Flutter 资源时的初始化超时；资源请求走主 isolate，文件校验与推理继续在后台完成。模型文件缓存于应用私有 files/rag_models 目录。
- Flutter 全量回归 2873 项通过、100 项按条件跳过；资源加载修复后 26 项相关回归通过，静态检查无问题。
- 正常应用入口已覆盖安装，原数据保留，现有 32 轮可用对话成功迁移；记忆页展开、输入与查询显示正常。实际英文安全承诺描述可检索出中文旧台账，但笼统的 “What did we promise about safety?” 未召回，说明短泛化问句仍有漏召回，不能把本版视为可靠的全量回忆系统。

验收数据为内存隔离的合成对话，原存档和 API 配置保留。未调用收费聊天、语音或 Embedding 接口；生成模型实际回答的措辞及长期自然聊天体验尚需后续观察。
