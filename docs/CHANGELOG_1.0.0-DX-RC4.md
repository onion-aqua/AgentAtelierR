# AgentAtelierR 1.0.0 DX RC4

Android 版本：`1.0.0-dx.rc4+35`。版本代码由 34 升至 35，可覆盖已有 beta6 安装。本次发布加密 release APK，GitHub 标签为 `v1.0.0-dx.rc4`，作为 RC 候选版本发布。

## 本次更新

- 背包支持食物、书本及生活用品等普通物品。开启 Agent 后，可在聊天中说“把一个苹果放入背包”，模型调用工具后写入真实库存，无需先旅行或采集。
- 入包时优先采用用户指定标签，其余按物品语义生成；标签可显示、保存和恢复，同轮重复调用不会重复添加同名物品。
- 修复旧存档缺少人物状态字段时沿用上一个存档状态的问题。
- 清除聊天并一并删除长期记忆时，同步重置当前人物状态、关系点数及剧情时钟；保留记忆时保留状态，已保存的其他存档不受影响。
- 修复新档精力、亲近感、好奇心数值与状态标签不一致的问题。
- 实际睡过一觉后，精力至少恢复到 80；剧情跨过一天以上至少恢复到 70。关闭剧情时钟也可以恢复精力，纯旁白同样支持结算。
- 多天剧情跳转支持最多 30 天。恢复在饥饿扣除之后结算，避免跳时消耗完全抵消恢复；不自动补满饱食度。
- 延续 beta6 的 CosyVoice 3 本地中日文 TTS、音色克隆与日文读音前端改进。

语义识别依赖模型正确判断和调用工具；否定、假设、只是计划睡觉或仅用户本人睡觉不应触发主角恢复。完整说明见[背包与状态恢复说明](背包与状态恢复说明.md)。

## 构建

使用项目的资源加密脚本并启用 Dart 混淆：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tool\build_protected.ps1 -Target apk -Mode release
```

APK 附件名：`AgentAtelierR-1.0.0-DX-RC4-release.apk`。当前工程仍沿用 Android 调试密钥签名，以兼容已有安装；这是 release 运行模式，不是商店正式签名包。苏菲立绘、其他本地角色资源及加密密钥不提交源码仓库。
