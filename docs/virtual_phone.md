# 虚拟手机使用说明

主界面点击手机图标进入桌面。点击桌面或底部图标时，页面从该图标的位置展开并铺满手机内容区；退出页面时，页面缩回对应图标。顶部状态栏在整个动画过程中保持显示。图标有轻微按压反馈，桌面随页面展开轻微缩小。

页面左上角返回、系统返回、手机内容区左右边缘向内滑动均按页面层级返回：先关闭当前确认框、抽屉或子页面，再缩回图标并返回桌面；在桌面返回会关闭手机。设置分类及表单的返回限制继续生效。边缘手势跟随手指变化，短拖松手可取消返回；支持 Android 预测返回的系统会使用同样的缩回动画。系统开启“移除动画”时立即打开和关闭页面。按住顶部短条向下长拖可直接关闭手机。

角色状态、服装、组合动作和存档均在手机内显示完整界面：

- 角色状态：心情、精力、亲近感、好奇心及最近变化、关系点数、饱食度和剧情时间（启用时）、服装姿态、地图位置、长期记忆开关。
- 服装：预览、切换、导入 ZIP、导入贴图、选择和删除导入贴图。换装后保持当前页面。
- 组合动作：自动姿态、自然坐姿、盘腿坐及当前资源支持的全部组合动作。选择后播放动作，保持页面。
- 存档：新建、保存、读取、重命名、删除、导入、导出。确认框在手机范围内显示；读取成功后保持存档页面。

桌面直接显示天数、时间、位置与天气，以及四列功能图标，省去中间的手机标题和“冒险工具”说明。功能图标行间距为 18dp，图标描述采用加粗文字和轻微暗色阴影，便于在壁纸上阅读。底部固定一行电话、信息、手机壁纸和自定义快捷图标，不随上方图标滚动。该行只显示图标，名称保留在无障碍提示中；没有 Search 按钮。电话暂为预留入口，信息可与当前角色世界中的 NPC 进行独立私信，详见 [NPC 信息与存档](npc_messages.md)。

桌面时钟参照手机截图使用大号粗体等宽数字、紧凑字距，以及浅蓝白半透明渐变和轻微柔光。字号按手机宽度调整，390dp 手机约 112dp，窄屏或大字体时自动缩小以保持单行；天数使用左对齐的小号标签。大时钟省略小时的前导零（例如 `09:41` 显示为 `9:41`），顶部状态栏及剧情时间数据保持原有格式。时间变化不使用闪烁或额外动画。

## 手机壁纸

手机桌面及桌面顶部状态栏默认使用用户提供的第一张壁纸（海边工坊）。另外两张内置壁纸为林间遗迹和落日海岸，三张均不能删除。

点击底部壁纸图标进入选择页。壁纸卡片始终按三列排列，可以上下滚动；点击卡片立即设为壁纸，勾选标识显示当前选择。列表最后的空白卡片中央有大“＋”，点击后从系统文件选择器导入图片，成功后自动使用。

页面左上方的删除选择按钮位于返回按钮右侧。进入选择模式后，只能选中后来导入的壁纸，再点击右上删除按钮并确认。返回会先退出选择模式；删除正在使用的导入壁纸后，自动恢复第一张内置壁纸。

导入图片会保存为应用私有目录中的独立副本，删除不会影响用户原始图片。壁纸列表和当前选择独立保存在本机，重启、切换角色、新建或读取存档后保留，不混入角色聊天备份。背景采用独立监听，背景与缩略图分别限制解码尺寸。导入图片最多 24 MB、3200 万像素、长边 8192 像素，保存的静态 PNG 长边最多 2560 像素。

三张内置资源位于 `assets/images/virtual_phone/bg1.png`、`bg2.png`、`bg3.png`，用户已允许公开，Git 忽略规则对这三张资源单独放行。

## 自定义设置快捷入口

首次点击“自定义”，选择设置首页的一项，即可将它设为快捷入口。可选界面与场景、声音与语音、用户设定、AI 接口、角色与世界、数据管理、关于，以及可用时的 PC Agent 联动。

设置后，快捷图标变为所选项的图标，名称可通过无障碍提示读取，点击直接打开实际设置页面。长按快捷图标可重新选择。也可长按设置首页的项目，或在设置分类标题右上角点击星标，将当前分类设为快捷入口。

选择独立保存在本机偏好中，重启后恢复，不会因切换角色或读取存档而改变。

## 显示区域

手机页面使用独立 Navigator 和手机尺寸的 MediaQuery。桌面顶部左侧显示虚构运营商，进入二级页面后显示时间；灵动岛贴图、LLM 信号与饱食度电量在页面和确认框打开期间均保留。状态栏下方直接显示完整页面，没有额外顶部或底部黑色预留边。按住顶部栏下拉仍可关闭手机；表单和确认框跟随手机内容区尺寸布局。真实系统文件选择器和权限窗口仍由 Android 显示。

新存档从“移动／电信／联通”随机选择运营商后缀，同一存档的后缀固定；地区前缀跟随当前地图，分别为库肯岛、克莱利亚、内米德、异界、王都。苏菲当前地图使用“异界”。后缀随存档保存、读取、导入、导出和角色切换恢复，旧存档会补齐并保存此信息。虚构名称不读取设备 SIM 卡，也不影响真实网络。

手机内标题栏统一为 56dp，公共返回按钮的点击区域为 48×48dp，与标题行居中对齐；PC 聊天历史和壁纸删除按钮为它预留位置。桌面在短屏或大字体下可滚动上方内容，底部四个图标固定；图标尺寸及文字行高按可用空间适配。

二级页面顶部状态栏使用与页面主题对应的不透明背景，深色页面使用白色文字和图标，浅色页面使用黑色文字和图标；信号及电量 PNG 按透明度着色。主题切换后立即同步，返回桌面恢复壁纸上的白色状态栏。PC Agent 返回按钮位于页面自身标题栏，打开历史侧栏后由侧栏及其遮罩覆盖；系统返回先关闭侧栏，再返回手机桌面。

液态玻璃开关实时同步到已打开的页面、卡片、图标、返回按钮和确认弹窗，无需关闭后重新打开；浅色和深色主题下使用对应文字颜色。关闭时，桌面的所在地区与天气卡片、底部图标栏使用明显的灰色半透明背景，开启后恢复液态玻璃样式。图片预览不叠加模糊，嵌套图标及内容卡片不重复增加背景模糊。持续 ASMR 播放时仍保持其专用黑屏显示。

## 信号与电量

信号来自真实主角色 LLM 请求，每 10 轮成功回复更新一次；自动剧情回复计入轮次，工具往返只算一轮。流式请求测量发送到首次非空文本返回的耗时，非流式适配器则测量到完整正文返回，不包含翻译、动作/表情规划或 TTS。

| 最近采样耗时 | 信号格数 |
| --- | --- |
| 不超过 10 秒 | 4 |
| 超过 10 秒、不超过 20 秒 | 3 |
| 超过 20 秒、不超过 30 秒 | 2 |
| 超过 30 秒、不超过 40 秒 | 1 |
| 超过 40 秒 | 0 |

首个采样完成前显示灰色未采样图标。失败、取消、空回复不会推进采样轮次，切换存档后的旧请求也不会改变当前信号。信号衡量 LLM 服务，切换存档保留最近值，应用重启后重新采样，不另发网络探测请求。

电量读取当前剧情时钟中的饱食度（0–100），关闭饱食度/剧情时钟开关时显示满电。图标区间依次为 0、1–10、11–25、26–50、51–75、76–100；填充量表示饱食度，图标颜色跟随状态栏明暗。长按顶部信号/电量可查看说明。

图标资源由用户提供的两张截图分别裁出，采用透明 PNG，主体约 90% 不透明度；灵动岛保留原始贴图。公开资源位于 `assets/images/virtual_phone/`，已单独加入 Git 忽略规则的允许列表。重新制作时使用 `tool/prepare_virtual_phone_assets.py`，通过 `--signal`、`--battery`、`--island` 参数传入源图路径。

PC Agent 图标现在进入完整聊天页面：左上历史侧栏、右上新开对话、底部输入，以及原有联动管理入口。真实桌面历史需要 PC 独立授权读取，详见 [PC-Agent聊天与历史.md](relay/PC-Agent聊天与历史.md)。
