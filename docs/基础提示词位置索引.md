## 1. 主聊天：先看真正生效的入口

当前调用链：`ChatScreen → AppController.buildCharacterPrompt → _buildCharacterPrompt / _buildSophiePrompt → AiServices.streamChat`。

- [主聊天调用](../lib/src/chat_screen.dart#L3719)固定传入 `independentPerformance: true`，因此莱莎常规主聊天使用 [2511 行开始的独立表演正文](../lib/src/app_controller.dart#L2511)。表情和动作由后续独立规划器生成。
- 莱莎当前默认人物卡是 **`compactCharacterPersona`**。用户自定义 `characterPersona` 非空时优先使用自定义文本；人物卡注入开关决定是否注入。
- `assets/data/runtime_prompts.json` 中的 `characters.ryza.system_prompt` **不是当前主角莱莎默认人物卡的来源**。
- 最终提示还会追加语言、译文、状态、服装、位置、剧情、记忆、NPC、联系方式和工具规则，不能只修改人物卡来修改全部行为。

角色 JSON 通过 [update/resource_resolver.dart:9](../lib/src/update/resource_resolver.dart#L9) 的 `ResourceAssetResolver` 读取：启用资源覆盖时优先读取已激活快照，否则回退内置资源。因此设备实际使用的 JSON 可能与内置文件不同。当前 Windows 不启用该资源覆盖。Dart 中的固定提示词需要代码版本更新，不能仅靠替换 JSON 修改。
