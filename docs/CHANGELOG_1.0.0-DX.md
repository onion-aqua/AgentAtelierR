# AgentAtelierR 1.0.0 正式版 DX

Android 版本号：`1.0.0+31`。GitHub 标签：`v1.0.0-dx`。

## 本次更新

- 页面切换改为旧页轻微缩小、模糊和半透明暗罩，再在目标资源就绪后让新页放大淡入。保留莱莎加载动画，并在新页出现时淡出。
- 地图提前读取数据和当前区域图片；读取失败时可在地图页重试。
- 服装页加入独立导入卡片：可导入服装 ZIP 或为指定服装导入贴图，并可切换或删除已导入贴图。
- 商店商品卡片保留名称、价格和购买操作；点击图片可查看描述及效果。
- 对话语音增加本地响度均衡，并改进人物嘴型、视线与动作表现。
- 记忆整理分为每 4 轮对话生成的最近记忆，以及累计 8 条最近记忆后的长期记忆；长期记忆整理提示词可编辑。
- 启用苏菲角色切换，隔离两位人物的设定、对话、记忆、存档及语音；苏菲目前使用静态立绘。
- 记忆页可立即整理并在确认卡片中修改内容及译文；历史对话保存译文。
- 持续 ASMR 的主题确认和播放分开，播放时进入黑色朗读界面并显示文字与译文。
- 调整对话控制标签过滤，减少未闭合标签误吞旁白。
- 食物图片在用户明确邀请莱莎品尝且模型确认内容后，可由本地工具结算饱食度；隐居处前可由莱莎每天准备两份食品补给，背包单组物品存档上限提高到 9999。

## 构建说明

使用 `tool/build_protected.ps1 -Target apk -Mode release` 加密构建，输出 `build/app/outputs/flutter-apk/app-release.apk`。人物资源和解密密钥仅用于本地构建，不上传源码仓库。

当前 Android 工程仍沿用调试密钥给 release 模式 APK 签名，可覆盖安装现有测试包；该签名不适合应用商店上架。
