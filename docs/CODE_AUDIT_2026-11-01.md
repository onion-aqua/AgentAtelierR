## 已确认并修复的问题

| 问题 | 触发条件与影响 | 修复位置与行为 |
| --- | --- | --- |
| 损坏的聊天缓存阻断启动 | 缓存是合法 JSON，但消息字段或整体结构类型错误，解析抛出 TypeError，原保底只处理 FormatException。 | `lib/src/app_controller.dart`：缓存读取失败时恢复初始会话并记录诊断。 |
| 空历史导入残留旧对话 | 备份显式包含 `messages: []`，原代码因列表为空而不替换旧消息；切换到空人物会话时也可能携带旧对话。 | `lib/src/app_controller.dart`：显式空列表清空历史，缺失字段保留原有兼容行为。 |
| 不含历史的导出仍携带原话 | 导出本地存档时取消“包含对话历史”，可见消息被移除，但 RAG 归档仍包含完整用户与角色原话。 | `lib/src/app_controller.dart`：同时清除 RAG 原文归档和对话检查点，保留整理后的记忆摘要；不修改原存档。 |
| 存档异步写入竞争 | 迟到的译文写入可在删除后重新写回槽位；保存期间切换人物会把活动槽位元数据写到新人物。 | `lib/src/app_controller.dart`：槽位保存、重命名、导入、删除及迁移复用写队列，并固定操作所属人物的存储键。 |
| 读取旧存档影响新会话 | 读取附件缩略图或迁移运营商信息时离页切换人物，迟到的结果可能修改新人物的活动槽位，或提前提升数据版本并取消新任务。 | `lib/src/app_controller.dart`：提交前核对人物、切换代次和数据版本，迁移固定原槽位，候选控制器在 finally 中释放。 |
| RAG 初始化失败后持续等待 | 目录、词表或 worker 启动失败时，共享初始化 completer 没有完成；并发和后续调用永久等待。 | `lib/src/rag_memory_embeddings.dart`：完成失败等待者、释放 worker/端口并允许重试；销毁和 worker 异常退出也释放等待者。 |
| 通话失败恢复发生自等待 | LLM/TTS 失败后恢复麦克风再次失败，当前 turn 等待挂断，而挂断又等待同一 turn 结束，导致挂断和重拨卡死。 | `lib/src/realtime_call/call_session.dart`：发起异步清理后退出当前 turn，再由清理流程等待其结束。 |
| 附件异常中断与大小限制绕过 | 系统文件选择器或单个文件 length 失败未处理；文档提供方报告的长度小于实际数据时，可突破 10 MB 单次上限。 | `lib/src/chat_screen.dart`：捕获选择器和逐文件异常、保留草稿和可读文件，并按实际读取的单文件/累计字节数再次验证。 |
| 导入页迟到回调覆盖数据 | 文件选择或云端文件读取尚未完成时关闭设置、切换分类或存档，旧结果仍可开始导入；选择器异常也位于 try 之外。 | `lib/src/settings_screen.dart`：捕获选择器异常，导入前核对页面、分类、controller 和数据版本。 |
| 更新请求覆盖用户的新设置 | 检查更新等待网络期间修改自动检查、下载源或忽略提示，迟到的请求用旧设置整体覆盖新设置；关闭自动检查后仍可能弹提示。 | `lib/src/update/update_service.dart`：只对短存储事务串行处理，提交时重新读取最新设置，网络不占用写队列；自动检查返回前再次检查开关。 |

另外，静态检查原先扫描了 `dist/` 内生成的 iOS 迁移样例，产生两个旧 `MyApp` 模板错误。`analysis_options.yaml` 现排除分发产物目录；没有以忽略生产源码的方式消除错误。
