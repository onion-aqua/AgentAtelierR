## 时序

| 时间 | 表现 |
| --- | --- |
| 0–1 秒 | 按钮轻微缩放，显示“莱莎正在醒来…”，播放皮肤内的触碰反应，保持闭眼 |
| 1–4.6 秒 | 播放已验证的 B12 伸展动作；嘴型渐开后渐闭，约 2.2 秒开始出现少量眼角泪光 |
| 4.6–5.8 秒 | 放下手臂、平滑睁眼，泪光淡出 |
| 结束 | 清理临时轨道，恢复之前的普通表情及微动作，解除输入锁 |

时间按角色实际渲染帧推进。重复点击不重播、不提前解锁。切换人物、服装或存档时取消旧演出；返回后台不通过延迟计时器跳过角色演出。静态立绘或模型未就绪时保留短点击反馈后解除输入，防止无法使用聊天。
