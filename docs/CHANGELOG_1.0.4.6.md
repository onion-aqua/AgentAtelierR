# AgentAtelierR 1.0.4.6

## 更新内容

- 新增本地 RAG 记忆试用：自动结合关键词和多语言语义检索过往对话，记忆随人物和存档保存，撤回与读档同步更新。
- 修复自定义人物、世界观提示词被截断或忽略的问题，减少内置性格与自定义设定的冲突。
- 过滤日语中省略号搭配的独立喘息片段，覆盖对话、历史、NPC 信息、电话字幕和 ASMR，保留正常词语与引述。
- 优化 Android 通话音频路由，连接蓝牙耳机时优先使用耳机，并同步显示实际输出设备。
- Windows 版同步本地 RAG 记忆、自定义人物与世界观修复、日语片段过滤，修复记忆模型运行库冲突和更新入口停留在旧版本的问题。

## 使用方法

- 打开“设置 → 数据管理 → 长期记忆”，使用“本地 RAG 记忆 · 试用”开关；展开“测试回忆”可查询本地记录，不生成聊天或语音。
- 在“设置 → 角色与世界”中编辑人物设定或世界书，保存后开启对应注入开关，下一轮对话生效。
- 已连接蓝牙耳机时直接拨打虚拟电话；通话中仍可手动切换输出设备。
- Windows 用户下载名称包含 `windows-x64` 的 ZIP，完整解压到新文件夹后运行其中的应用程序；请保留同目录的 `data` 文件夹和 DLL。

## 注意事项

- RAG 为试用功能，仍可能漏召回；旧版已经丢失的对话原文无法恢复。初次使用需加载本地模型，包体和存储占用有所增加。
- 更新前建议导出本地数据备份。此次包含程序代码更新，需要按系统提示确认安装；可直接从旧版本更新至此版本。
- Windows 版适用于 Windows x64；暂不提供实时电话、闹钟和本地 TTS，更新页面提供完整安装包下载入口。
