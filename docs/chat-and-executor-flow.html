组件分类

类型组件职责是否是 Agent 工具 / 子智能体
界面编排层 ChatScreen、AppShell 接收输入、管理回复状态、驱动消息显示、串联后处理。 都不是。它们是客户端流程编排者。
状态与领域层 AppController、炼金、任务、地图、记忆模型 保存消息、用户状态、角色状态、任务、库存、地图和长期记忆；提供本地业务操作。 不是子智能体；其中被暴露给模型的方法才形成 Agent 工具实现。
模型传输层 OpenAiCompatibleClient、_geminiChat、PlanningHttpClient 发送普通对话、Agent 决策、辅助规划请求，并解析流式响应。 不是。它们是 LLM 客户端和传输组件。
Agent 工具定义 _agentTools 中的 web_search、任务、炼金、地图、设备工具等 向模型声明可调用的函数名称、参数和说明。 是“模型可调用工具的声明”，不是独立子智能体。
Agent 工具调度器 _streamAgentChat、_executeToolCall 请求模型决策、解析 tool call、路由执行、回填 tool 结果、循环直到最终回答。 这是 Agent runtime / 工具执行循环，不是单个工具。
Agent 工具实现 AppController.queryContextTool、DeviceAgentTools、WebSearchClient 执行本地业务状态修改、设备查询和网页搜索。 是工具实现；不是子智能体。它们不会自行决定下一步。
辅助规划器 IndependentPerformanceTools、ExpressionPlannerTool、ActionPlannerTool、SpeechPlanner、SingingPlannerTool 在主回复生成后，用专用提示词生成表情、动作、姿态和语音标签；结果经过本地 JSON 与能力校验。 不是 Agent 工具，也不是子智能体。它们是客户端主动调用的 auxiliary LLM tasks；即使内部调用 LLM，也没有 Agent 工具循环和自主目标。
规则解析与校验 chat_segments.dart、PerformancePlanner、各类 Plan.apply 拆分说话者、提取控制标签、校验候选、合并规划结果，必要时回退。 不是。它们是本地纯处理逻辑。
角色表演执行器 CharacterPerformanceQueue、_drainPerformanceQueue、_playSemanticActionNow、_playMotionGroupNow 检查 Spine 状态、姿态和资源兼容性，排队并播放动作，完成后恢复待机。 不是 Agent。它是确定性的运行时执行器。
语音执行器 FishAudioClient、DashScopeTtsClient、GenericTtsClient、MimoTtsClient 把规划后的莱莎台词合成为音频，并驱动播放、口型和语音缓存。 不是 Agent。它们是外部 TTS 服务适配器。
持久化与观测 SharedPreferences、ConversationCollectionStore、RuntimeLog 保存消息、设置、语音片段、运行日志和诊断信息。 不是。它们不参与模型决策。

判断标准

只有同时满足“出现在 _agentTools 声明中、由模型发起调用、经过 _executeToolCall() 路由”的组件，才属于 Agent 工具链。规划器虽然可能调用 LLM，但它们由 ChatScreen 在主回复之后主动调用，输出的是受校验的计划数据，因此归类为辅助规划器，不归类为 Agent 子智能体。
