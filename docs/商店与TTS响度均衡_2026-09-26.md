# 商店与 TTS 响度均衡

## 商店

商品卡片显示商品图片和名称，底部左侧为关系点数价格，右侧为「购买」按钮。卡片上不显示描述和效果；点击商品图会打开详情卡片，按商品名、预览图、描述、非空效果的顺序显示。购买扣费、背包和物品效果使用原有逻辑。

## 服装切换

保留卡片滑动和过渡动画，移除旧的右下角多按钮组。页面底部仅保留「切换」按钮。所有服装后新增一张等分的导入卡片，上半区导入服装 ZIP，下半区导入贴图。

ZIP 包内有独立预览 PNG 时，导入后自动显示在新服装卡片上并随包保存。支持同名 `_preview.png`、`-preview.png` 及 `preview.png`、`cover.png`、`thumbnail.png`；缺少预览时显示占位。导入贴图时先选 PNG，再选择对应服装，验证图集尺寸后启用，并在该服装卡片显示替换贴图后的 Spine 静态预览。已导入贴图的卡片左上角提供原始/导入贴图切换菜单。

## 语音

对话 TTS 在合成完成后、播放和缓存之前自动执行本地响度均衡，覆盖 Fish Audio、DashScope、通用 TTS 和 MiMo，以及使用同一流程的持续 ASMR。

- 每 20 毫秒分析能量，用平滑增益缩小句内和分段间的音量差。
- 普通语音参考 RMS 为 0.12，最大提升约 8 dB；ASMR 参考为 0.065，最大提升约 3.5 dB，压缩也更轻。
- 静音不触发增益追踪，相邻窗口峰值约束避免削波，左右声道使用相同增益。
- 生成标准 PCM16 WAV，保留采样率、声道和采样帧数，不改变语速或音高。播放器仍叠加用户设置的总音量。
- WAV 处理和嘴型振幅分析在后台 isolate 执行；Android 压缩格式用系统解码器在工作线程解码，再做相同处理。
- 解码失败或超出处理限制时记录日志并回退原音频，避免打断对话。压缩音频处理限制为系统解码器支持的格式；其他平台当前仅均衡支持的 WAV。
- 新生成的缓存保留均衡结果，重播不重复处理；已有历史语音文件不会被批量改写。

这是轻度动态压缩与能量均衡，不是广播标准 LUFS 计量。已经被服务端削波的音频无法恢复。处理加入少量播放前开销，实际听感仍需真实语音试听确认。

## 手动长期记忆建议（本轮不实现）

建议在长期记忆页面加入「立即整理」，支持选择「上次整理后」「当前存档全部可用对话」或时间范围，并在开始前显示覆盖范围。长历史分批提取事件后合并，避免只取最后一段导致遗漏。

生成结果先显示新增、修改及可能冲突的条目，用户确认后写入。默认保留旧条目，不让一次整理静默删除已有记忆；保存旧版本以便撤销。每条记忆保留来源消息或时间，方便核对漏记。

手动入口与自动整理独立，运行时禁用重复点击；切换存档或有新记忆写入时，重新核对目标和版本。失败保留原记忆。现有自动整理逻辑此次未修改。
