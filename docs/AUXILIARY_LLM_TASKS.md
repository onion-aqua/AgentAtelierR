# 独立翻译与记忆整理

主对话只生成原文、旁白和表演标签。应用通过 `DialogueTranslator` 独立翻译，通过 `MemoryConsolidator` 独立整理记忆；两个模块都没有 Agent 工具权限。

## 第一版配置

复用本轮主对话的接口、模型和安全存储中的 API Key，没有新增密钥。辅助请求使用最小专用提示词，已知模型按能力关闭思考或使用低推理强度。未知接口沿用服务端默认参数。不改变 TTS 的专用服务配置。

复用密钥不代表免费，也不代表上下文共享。当前没有独立轻量模型选择框，是否降低总费用需要实际统计。

## 翻译

- 关闭翻译时不发请求；开启后，在一轮原文完成时批量提交角色台词，包括 NPC，不提交附件或完整角色提示词。
- 每条台词携带段落编号，输出必须完整匹配编号；标签、旁白不参与翻译。非法、重复、缺漏结果不应用。
- `ChatMessage.text` 保留原始输出，供上下文、原始输出查看和 TTS 使用；`translatedText` 为独立显示副本，随存档保存，兼容不含该字段的旧存档。
- TTS 与翻译并行；译文完成后更新显示和当前朗读段落索引。只显示译文模式在翻译未就绪或失败时回退原文。
- 翻译失败提供原文和重试提示；已撤回、清空、读档或切换目标语言的过时结果不会回填。
- 第一版按整轮批量翻译，尚未实现流式逐句翻译或全局术语表。

## 记忆

- 保留每四轮/重要事件触发方式，独立后台整理，不等待翻译、不阻塞 TTS；下一轮对话不会取消已触发的整理。
- 排队时保存已完成对话的快照，避免后续整理混入下一轮尚未生成完整的回复。运行日志记录触发、合并、成功或丢弃原因。
- 单次只运行一个整理任务，重叠触发合并成一次后续处理。
- 当前会话成功整理后记录用户消息检查点，后续只发送检查点之后的新对话及旧记忆。首次启动或检查点已不在历史中时使用最近十二条；检查点不写入存档。
- 本地校验结构、合并保护重要记忆；无效结果保留旧内容。记忆手动变更、数据替换、禁用记忆或相关用户消息被撤回后，丢弃旧请求结果。
- 当前仍由模型返回合并后的记忆集合，不是增删改补丁协议。

## 验证范围

单元测试覆盖批量 ID 绑定、NPC 翻译、标签隔离、异常结果、原文保存、过时消息回填、译文缺失回退与重要记忆保护。在线延迟、费用和角色口吻需要配置真实服务后验收。
