# 独立语音演出

设置位置：声音与语音 → 语音合成 → 独立语音演出。默认开启，支持本地保存和备份恢复。Android、Windows 共用实现。

开启后使用当前 LLM 配置发起专门的语音规划请求，与肢体表演规划并行。模型返回情绪及标签插入位置，本地从原文重建合成文本，不接受模型改写台词。关闭时恢复主模型语音标签规则。两种模式都保留感情程度、句内演出密度及 ASMR 设置。

规划最多等待 8 秒，异常时回退本地处理；单个越界或无效标签会被忽略，不再使整个规划失效。合法的句内情绪标签也能保留。合成、重试和播放仍由应用执行。额外模型请求会增加使用量并可能增加等待时间。

Fish Audio ASMR 音色未填写或清空保存时使用 `c5de0b3f9ac54e08b21fb63120e4ebdb`。普通模式音色不变，填写自定义 ASMR 音色会覆盖默认值。音色是否可用仍受服务端账户权限和模型支持影响。

## 对话动态

说话时允许当前姿态资源配置中的躯干小动作，主动动作和触摸保持优先。修正头部、身体 roll 控制点的 IK 位移，并为自动眼神使用眼球骨骼位移。动作混合保留资源时长并设置平滑下限。实际各皮肤视觉表现仍需运行验收。

## 构建 Windows Release

资源准备见 RESOURCE_SETUP_AND_BUILD.md。使用 `./tool/build_protected.ps1 -Target windows -Mode release`。打包整个 `build/windows/x64/runner/Release` 目录，包含 DLL 和 data，不能仅分发 EXE。密钥和原始素材不得加入 Git。
