# TTS 立体声与固定声音位置

## 使用方法

在“设置 → 声音与语音 → 语音合成”中开启“立体声”，再选择“固定声音位置”：居中、偏左或偏右。默认关闭，首次开启时默认居中。普通聊天语音、持续 ASMR 和各 TTS 服务的试音使用同一套设置，建议戴耳机体验。

- **居中**：人声保持在中央，只加入很轻的固定空间感。
- **偏左 / 偏右**：人声固定在对应一侧；持续 ASMR 的侧耳效果略强于普通语音。
- 声音位置由用户选择，不随机变化，也不会被台词、情绪规划或人物动画改写。无需给 LLM 添加声道指令。

一整段普通回复采用开始合成时的设置，一次持续 ASMR 会话采用点击“确定”时的设置。播放或预缓冲期间调整开关和位置，下一段回复或下一次 ASMR 会话才使用新设置。重播及收藏的音频保留生成时的效果；旧音频不会被重新处理。

这是全局听音偏好，会保存并随设置备份导入、导出。切换角色、读取存档或创建新存档不会改变它。旧备份没有这两项时，恢复为关闭、居中。

## 声音处理

单声道以及左右几乎完全相同的双单声道音频，在响度均衡后转换为双声道 WAV。侧耳效果使用固定声像、远耳的轻微高频衰减和不足 0.4 毫秒的耳间时差；居中效果保留共同的直接人声并添加很轻的固定短反射。

这些处理模拟固定的听音位置，不能还原真实双耳录音中的所有空间线索。已有真正立体声的音频保留原有声场，所选位置不会覆盖它。关闭开关时不添加空间效果，源文件本身的声道数也不会被强制改成单声道。

解码、响度和空间加工沿用本地后台处理，不增加 TTS 服务请求。输出保持采样率、音频帧数和时长，口型和语音演出仍根据处理后的音频同步。不能解码或超出处理上限的音频回退为原音频播放。

## 验证范围

音频测试覆盖固定声位、左右镜像、声道转换、时长、峰值、静音、原生立体声保留及损坏文件回退。播放链路测试使用本地测试服务验证普通回复和持续 ASMR 的预缓冲设置快照；设置测试覆盖持久化、备份、角色切换及中英日界面。

2026-10-10 已通过加密脚本构建 Android debug 包，并在模拟器执行原生音频检查，覆盖 MP3 解码、单声道及固定声位立体声 WAV、字节音源和 40 段连续播放。相关结果与错误恢复范围见 [持续 ASMR 音频加载可靠性修复](asmr_audio_reliability.md)。

模拟器检查与自动化测试不代表已经通过真机耳机试听。实际听感、用户手机上的 Fish Audio 连续播放仍需复测。本功能随 `v1.0.4` 正式版覆盖更新交付，使用资源加密、Dart 混淆的 Android 与 Windows release 构建。
