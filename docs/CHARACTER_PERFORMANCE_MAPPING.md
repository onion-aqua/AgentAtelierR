# 角色表情与动作映射表

## TTS 同步演出

- 每条“莱莎：”台词是独立演出单元，旁白只显示、不合成语音。
- 聊天播放固定向 Fish Audio 请求 WAV，以便从 PCM 计算口型包络；下一句会在当前句播放时预取。
- 音量包络以 20 ms 为一帧，约 40 ms 起音、90 ms 收音，并把嘴部张开限制在 55%。
- 对应表情、语义动作和头部微动只在该句音频真正开始播放时启动。
- 未启用 TTS、密钥缺失、WAV 无法解析或合成失败时，保留文字时长估算作为降级。

### 口型闭合与面部细节

- 参考原始 gesture 的 `lipSyncClosure`：20 ms 音频帧使用快速起音、慢速收音，并在约 120–240 ms 的窗口内寻找低能量点。
- 每次闭嘴至少保持约 60 ms；嘴部 scrub 最大进度限制为 48%，避免长时间大张嘴。
- 无 TTS 的降级演出也使用约 5.2 Hz 的合成开闭节奏，不再循环播放持续张嘴动画。
- 九类 `face` 情绪分别使用原始 `EmotionProfilesV4.expressionSets` 中确认存在的眼睛和眉毛组合。
- 说话时每约 1.5–3.1 秒轮换一次兼容的面部细节，并每约 1.7–3.5 秒自然眨眼一次。
- 所有候选动画在播放前检查当前骨骼是否存在；点击表情激活时暂停微表情，避免覆盖原始点击反馈。

## 设计边界

原始两套 gesture 配置都包含 9 个情绪族：`neutral`、`happy`、`laughing`、`angry`、`sad`、`crying`、`shy`、`tease`、`cuddle`。应用只使用这 9 类可确认的表情，不凭动画文件名猜测新的表情含义。

LLM 不输出 Spine 动画名。每条角色台词输出三个机器标签：

```text
莱莎：[Fish Audio 情绪][face:表情][action:语义动作] 台词
```

例如：

```text
莱莎：[excited][face:happy][action:excited] 太好了，这个素材一定能派上用场！
```

`face` 和 `action` 只供应用演出，显示和 TTS 前都会移除。

## 表情映射

| 表情标签 | 使用语境 | 视觉组成 | 避免使用 |
| --- | --- | --- | --- |
| `neutral` | 平静陈述、普通衔接 | 不固定高层脸部轨道，释放给原始 idle 眨眼和微表情 | 连续多句都使用 |
| `happy` | 开心、发现有用素材、轻松回应 | 柔和眼型、上扬眉、轻微笑嘴 | 严肃警告、安慰伤心用户 |
| `laughing` | 真正好笑、成功后的短暂大笑 | 笑眼和笑嘴 | 普通礼貌回应，避免一直笑 |
| `angry` | 坚定反驳、制止危险行为 | 收紧眼眉、严肃嘴型 | 轻微意见不同 |
| `sad` | 担心、失落、共情 | 下垂眉眼和收敛嘴型 | 仅因用户难过就机械复制 |
| `crying` | 强烈悲伤、剧情性落泪 | 悲伤脸加泪层 | 日常小挫折 |
| `shy` | 被夸、不好意思、轻微害羞 | 回避眼神、脸红和收敛笑嘴 | 无关系铺垫的亲密内容 |
| `tease` | 善意调侃、俏皮反问 | 侧目、挑眉和狡黠笑嘴 | 严肃解释、用户明显难过时 |
| `cuddle` | 温柔关心、安慰和陪伴 | 柔和眼眉、脸红和温暖嘴型 | 操控式依赖或夸张亲密 |

强表情在说话结束后保留约 4.6 秒，然后释放脸部覆盖层，让基础 idle 恢复自然微表情。

## 语义动作映射

| 动作标签 | 应用时机 | 坐姿优先动作 | 站姿优先动作 | 失败降级 |
| --- | --- | --- | --- | --- |
| `none` | 普通衔接、不需要明显肢体动作 | 不额外播放 | 不额外播放 | 保持 idle |
| `acknowledge` | 赞同、确认、听懂 | 点头一次 | 点头一次 | `oneshot D001` |
| `disagree` | 否定、拒绝、制止 | 摇头/否定动作 | 摇头/否定动作 | `oneshot D003` |
| `think` | 推理、回忆、权衡材料 | 托下巴或抱臂 | 抱臂或摸脸 | 提问类 one-shot |
| `explain` | 讲解步骤、提出方案 | 指向或说明手势 | 单手向前说明 | 提问类 one-shot |
| `excited` | 新发现、调合成功、准备冒险 | 双手握拳振奋 | 双手挥动 | 赞同类 one-shot |
| `wave` | 问候、告别 | 双手或单手挥手 | 单手或双手挥动 | 保持表情 |
| `shy` | 被夸、害羞、轻声表达 | 手靠近嘴边 | 背手或耳语手势 | 仅保留害羞表情 |
| `surprised` | 意外发现、突然状况 | 双手慌张 | 身体轻微后仰 | 提问类 one-shot |
| `comfort` | 安慰、关心、邀请靠近 | 双手向用户伸出 | 单手温和伸出 | 仅保留温柔表情 |
| `playful` | 善意调侃、活泼互动 | 双手比手势 | 猫爪手或摸脸 | 仅保留俏皮表情 |

底层映射定义在 `lib/src/character_performance.dart`。同一个语义动作对坐姿和站姿使用不同动作组，避免混用骨骼和手臂姿态。

## 动作安全规则

1. 组合动作只有在 `ApplicablePoseIds` 包含当前基础姿势时才播放。
2. LLM 标签只映射到白名单动作，不接受原始动画名、轨道名和动作组 ID。
3. 同一条流式回复中的同一个动作标签只触发一次。
4. 语义动作之间至少留出短暂间隔；没有动作时每 2.8 至 4.6 秒可播放一次兼容的轻微身体摇摆。
5. 组合动作结束后清除轨道 2 至 10，并恢复当前基础姿势，避免手部残留或材质错位。
6. 点击动作播放时暂时清除脸部轨道 11 至 16，让 `motion_touch_*` 自带的点击表情显示；结束后再恢复当前 LLM 表情。

## 自动动作调度

- 坐姿的 140 条、站姿的 53 条原始 `MotionGroups` 都会进入候选池，不再只固定使用少数手势。
- 默认约 80% 按原始 `EmotionProfilesV4.armGroupWeights` 选择符合当前表情的动作，约 20% 从当前姿势的完整兼容池中探索。
- 最近 5 个动作组 ID 优先去重；只有当其他候选都用尽时才允许重复。
- 说话时约每 1.8–3.8 秒触发轻量手势，排除占用 `C` 轨道的大幅换姿；闲置时约每 3.8–7.4 秒触发，可使用完整兼容池。
- LLM 语义动作的优先级更高；语义动作播放后 2.3 秒内不插入自动动作，避免两套手势互相覆盖。

## 说话动态

- 坐姿口型使用较小幅度的 `scrub_01`，不再用偏笑且张口较大的 `scrub_02`。
- 口型层透明度约为 `0.56`，播放速度为原来的 `0.82`，保留当前情绪嘴型的基础轮廓。
- 站姿资源没有对应的 `scrub_01`，继续使用已有 scrub，但同样降低混合权重和速度。
- 说话时优先驱动原资源的 `control_roll_head/control_roll_neck` 控制骨；头部使用明显的慢摆、分句包络点头和颈部延迟补偿。`control_roll_body_upper/control_roll_body_lower` 以更小幅度和不同相位跟随，让整个上身参与说话演出，避免只有头部细碎抖动。
- 等待 LLM 返回时不提前张嘴；收到首个文本增量后才开始说话动画。

## LLM 选择原则

- 表情反映角色自己的状态，不机械复制用户情绪。
- 平静内容允许 `neutral`，但连续内容应根据语义选择更具体的表情。
- 一个段落只选择一个主要动作；情绪或意图变化时另起角色台词行。
- 安慰不得搭配 `laughing/playful`，严肃说明不得搭配 `shy/playful`。
- 大动作只用于明确的语义节点，普通衔接使用 `action:none`。
