# 聊天气泡与菜单的轻量玻璃

视觉参考：[design-systems / Lens](https://github.com/ruiqichenbiec/design-systems/tree/7a424c93b9be13cf835b91ea67495fec2ec0584e/lens)，MIT，许可文本保存在 `docs/third_party/design-systems-LICENSE.txt`。

这是 Flutter 原生材质适配。参考透明中心、方向性边缘高光、内侧暗边和宽而弱的环境反射；没有嵌入该项目的 WebGL 渲染器，也没有实现它的完整物理折射。

- `ChatGlassSurface` 的 `bubble` 与 `menu` 变体分别供聊天气泡和长按菜单使用，跟随现有液态玻璃开关。关闭后保留普通背景。
- 关闭效果后，用户气泡采用当前主题的 `primaryContainer`，角色气泡采用 `surfaceContainerHigh`，正文用对应的可读前景色；切换主题色、浅色或暗色时即时跟随，用户明确选择的文字颜色继续优先。
- 输入框、音频条与收藏控制条的普通背景采用 `surfaceContainerHigh`（90% 不透明度），文字和图标采用 `onSurface`，音频进度及滑块使用主题主色。普通、三栏输入和加号均保持原位置。
- 气泡实际局部模糊 sigma 为 0.8，菜单为 1.12。菜单整块仅采样一次背景，每个选项不再增加滤镜。保持文字、头像与图标原有清晰度。
- 消息列表内互不重叠的气泡共用一个 `BackdropKey`，允许 Flutter 引擎合并背景采样。菜单、顶部过渡、输入栏和音频条不参与该组，避免重叠材质相互干扰；开关切换时保持分组及输入草稿、滚动状态。
- 滚动期间暂停消息气泡的背景模糊，透明底色和高光继续保留；停止后恢复。只在滚动开始/结束重建材质，不随滚动距离逐帧更新参数。
- 高光由圆角矢量绘制。触摸短暂提亮；移动超过 10 个逻辑像素即清除，松开/取消时复原。不抢占长按或滚动手势，不运行常驻 ticker。
- 菜单出现时仅缩放 140 毫秒，避免透明度离屏层阻断背景采样。系统减少动态开启时取消入场动画及触摸提亮。
- 菜单按触点定位，同时限制在安全区和键盘上方。大字体时内部可以滚动，旋转与窗口变化后重新定位。

性能验收区分模拟器与真机：组件/像素测试验证滤镜范围、手势、可读性与状态保留；模拟器 release 的帧采样只能说明该测试环境，不能替代不同手机 GPU 的验收。

本地 UI 预览通过实际 `AppShell` 展示，包含左上角隐藏／恢复 UI 按钮及原有全屏逻辑；使用内存配置与禁用联网的中继、更新服务，避免遗漏主界面外层控件或操作真实存档。
