# 对话默认微动增强与验证

对话朗读期间，头部偏转的程序化增益最高为原来的 1.4 倍，身体摆动最高为 1.55 倍。实际显示仍受每套资源的 yaw、pitch、roll 限制，达到限制时不会继续放大；这些倍数不是屏幕中固定的角度倍率。

## 实现

- 使用独立说话状态混合值，约 350ms 渐入、900ms 渐出。音频的单个音节响度只用于嘴型，不会导致头部或身体抖动。眼睛没有额外增幅。
- 对话时每 2.8～4.6 秒检查一次自然动作机会。正常坐姿有 45% 的晃脚机会，使用原有 `grp_c_01`，alpha 从 0.45 提高到 0.72，两次腿部动作启动至少相隔 6 秒。
- `grp_c_01` 的正常坐姿变体为 C001、C004、C006、C007。资源兼容性、可播放姿态和变体权重继续由原有选择器校验。站姿和盘腿不会套用这些坐姿腿动画。
- 默认晃脚可同时伴随头部和身体微动；作者编写的躯干动作仍屏蔽程序化头部与身体偏移。
- 明确动作、待执行动作、触碰和手指注视具有优先权。明确意图到来时，仅释放自动动作租约，避免等待默认动作的整个保持窗口；已有明确动作租约继续保留。触碰结束后不重播旧的自动动作。
- 切换角色或存档时清空自然动作租约及腿部冷却记录。暂停人物动画、持续 ASMR 等状态继续使用原有行为。

生产入口为 `lib/main.dart`；模拟入口 `tool/debug_animation_pipeline.dart` 不被生产入口导入，也没有放进正常 release 的运行流程。

## 验证

`flutter analyze --no-pub` 通过。新增策略及导演集成测试共 17 项通过，覆盖渐入渐出、休息状态、眼睛不变、音节能量隔离、明确姿态不增幅、触碰与注视保护、资源限幅和 10000 帧无漂移。相关动作选择、动作租约、播放时序及晚到规划分发测试通过。启用本地 Spine DLL 后，原生资源及播放时序 17 项通过。

额外真实原生探针验证六套资源各 3600 帧，以及四种正常坐姿腿变体：骨骼与网格顶点均为有限值、根骨无位移，退场后控制骨与腿部网格恢复。原生资源坐标中的位移不是手机屏幕像素，不能直接解释为可见角度。

Android 16 / API 36 的 `emulator-5554` 验证采用真实 ChatScreen、加密 Spine 和真实动画轨道，LLM 与 TTS 为明确标注的本地测试 transport 和模拟音频，不涉及在线服务联调。

| 场景 | 结果 |
| --- | --- |
| 自然长对话，20 秒模拟语音 | 录屏可见头部偏转、身体微动与晃脚；C007 在轨道 3 执行，其他躯干动画按原有过滤播放 |
| 拍手，20 秒模拟语音 | 录屏可见双手抬起、拍手、恢复；F050/G050 双轨同时入轨 |
| 双手问候，15 秒模拟语音 | 录屏可见双手问候；目标双轨同时入轨，默认微动不会抢占该动作 |
| `grp_recipe_4673`，15 秒模拟语音 | 骨骼与轨道采样确认 F050/G050 同时执行；阶段持续 901.6ms，随后释放，下一采样已为空轨道。此次组合动作以轨道采样验收，录屏抽帧未捕获其峰值 |

采样间隔为 100ms，最长观察间隔分别为 139、115、119、117ms。观察间隔不能代替真实渲染帧率或性能测试。四个场景均未出现非有限采样字段或读取异常；有效长语音场景均只请求一次 TTS。

证据：

- `evidence/conversation-live-summary.json`：四个场景的源文件哈希、轨道时间和骨骼范围。
- `evidence/conversation-motion-natural-overview.png`：自然对话抽帧。
- `evidence/conversation-explicit-overview.png`：拍手及双手问候抽帧。
- `evidence/conversation-motion-first.mp4`、`conversation-motion-final.mp4`：实际模拟器录像。
- `evidence/conversation-native-gain.json`、`conversation-leg-variants-native.json`：原生资源探针结果。

开发过程中有一份短台词配 20 秒音频的测试被已有超长 TTS 防护拒绝并重试，已使用长台词重新测试；该次不作为成功验收。
