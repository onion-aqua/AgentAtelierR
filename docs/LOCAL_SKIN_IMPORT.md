# 本地皮肤和贴图导入

在聊天页打开服装切换界面，滑到所有服装后面的导入卡片。上半区导入皮肤 ZIP，下半区导入贴图。文件只写入设备的应用私有目录，不上传服务器或 GitHub，不修改内置加密资源。

## 导入皮肤 ZIP

目前支持与现有莱莎动作系统兼容的 Spine 4.2 单页图集。ZIP 根目录或子目录应提供同名前缀的四个文件，例如：

```text
crf_skn_002_0002_01.atlas
crf_skn_002_0002_01.png
crf_skn_002_0002_01.skel
crf_skn_002_0002_01_gesture.json
```

ZIP 中可附带一张独立的预览 PNG，文件名为同名前缀的 `_preview.png` 或 `-preview.png`，也支持 `preview.png`、`cover.png`、`thumbnail.png`。通过校验后，新增的服装卡片会显示预览图；需要穿上时点击底部“切换”。没有独立预览图时显示占位，不把纹理图集当作预览。当前不读取 ZIP 中的任意脚本或其他附带文件。ZIP 和展开后的总数据均限制为 64 MB；不支持多页图集。

## 替换贴图

1. 在导入卡片下半区点击“导入贴图”，选择 PNG，再选择这张贴图对应的服装。
2. PNG 必须与所选服装原图尺寸相同，各部件的位置、旋转和 UV 排列也必须一致。尺寸相同只能说明图集大小兼容，不能自动判断绘制内容是否对应。
3. 导入后会定位到所选服装，卡片显示替换贴图后的 Spine 静态预览。该卡片左上角的贴图菜单可切换“原始贴图 / 导入贴图”；“导入贴图”右侧的删除按钮可移除导入的 PNG，并恢复原始贴图。已穿着的服装会立即重新加载。原始骨骼和动作配置不变。

导入皮肤及贴图选择在重启后保留。不同皮肤各自保存一张替换贴图；重新导入替换图会更新当前皮肤的选择。导入资源不包含在聊天 JSON 存档中，换设备需重新导入。仅使用你有权使用的素材。
