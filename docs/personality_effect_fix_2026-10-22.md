# 人格预设表现偏弱修复

## 设备证据

2026-10-22 只读检查已连接物理设备的人格配置与现有请求日志。当前角色为莱莎，已开启人格及对话表达，预设为 `mischievous_teaser`，调侃值 100，玩心值 98，整体强度 70。

最近主聊天请求使用 `gemini-3.8-flash`，包含人格段落，但将最高调侃值描述为“喜欢轻度调侃”，同时包含“玩笑程度较低”。预设保存的常态描述与说话风格未进入该段落。确认不是用户没有开启预设。

## 修改

- 普通对话无需命中情境关键词，也注入预设的常态描述和说话方式；手动参数优先。
- 区分最高档与中等档的调侃、玩心及语音倾向。最高档明确指导短句反问、俏皮挑战、接梗与逞强。
- 明确人格控制说话风格，身份、语言、世界观、事实及输出格式仍沿用原有配置。
- 整体强度决定台词表现要求；喜剧夸张力度不再被误写为调侃频率。
- 保留拒绝、认真求助、痛苦情境下的收敛，保留关闭开关和强度为零时的原行为。
- 人格提示词仍限制在 1200 字符内；无需重建预设或清空存档。
