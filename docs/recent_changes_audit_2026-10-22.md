# 最近修改回归检查与修复

核对日期：2026-10-22。范围为当前工作区最近的冷启动睡眠、玻璃材质、虚拟手机路由、记忆兼容整理、通话 MCP/API 选择及受公共组件影响的界面。保留工作区已有改动；此次修复位于 Android / Windows 共用 Dart 代码。

## 已发现并修复

| 问题 | 影响与原因 | 修复 |
| --- | --- | --- |
| 玻璃开关销毁内部控件状态 | 原先切换时添加 / 移除 `LiquidGlassOptics` 包装，输入框被卸载并重建。新增测试实际复现 `EditableTextState` 已销毁，焦点、选择区及控件内草稿不能保持 | 保持固定控件树，通过 `enabled` 停用背景滤镜、光泽和触摸监听；连续开关保留同一个输入框及光标位置 |
| 通话模型继承被悄悄变成覆盖 | 保存的 `fishModel` 为空时，设置页把当前默认模型写入输入框，保存后变为固定 ID；原校验还不允许空值。新增测试复现空值变成 `s2.1-pro` | 默认留空继承，默认模型仅作 hint；增加“跟随语音设置”操作，允许保存空值。已有明确覆盖值不迁移或删除 |
| 浅色模式下固定白色文字 | 全屏旁白输入和组合动作页仍固定使用白色文字，新的玻璃背景却跟随浅色主题 | 全屏输入、提示、分隔线和动作页文字 / 图标跟随主题；动作页使用统一页面 / 卡片材质 |
| 明亮场景降低聊天文字对比 | 低遮色玻璃适合装饰，但白色台词所在的大面积聊天区域缺少足够衬色 | 仅为主聊天、历史弹层及全屏编辑等文字区域启用对比底色；保留折射和流光。黑 / 白背景上的白字及次级白字像素对比度均验证不低于 4.5:1 |
| 睡眠时拨号提示错误 | 新增睡眠锁让 `canStart` 返回 false，但提示仍然让用户等待回复或关闭 ASMR，无法说明真正解锁方法 | 明确提示回主聊天点击“叫醒莱莎”；测试确认该路径不启动 ASR、不准备 MCP、不读取 REST Key、不生成音频 |

关键实现：

- `lib/src/glass_ui.dart`、`lib/src/liquid_glass_optics.dart`：稳定控件树与文字对比模式。
- `lib/src/chat_screen.dart`、`lib/src/narration_composer_fields.dart`：主题配色、主聊天及全屏输入。
- `lib/src/realtime_call/call_settings.dart`：模型继承和明确覆盖。
- `lib/src/realtime_call/call_session.dart`：睡眠拨号提示。
