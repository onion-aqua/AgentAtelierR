## 执行链路

主对话模型生成台词和旁白 → 独立 PerformancePlanner 选择情绪、强度、动作、姿态 → 本地校验 → 各段播放时应用 → TTS 仅接收剥离控制标签后的文字。

动作：动态枚举当前资源全部 MotionGroups，检查骨骼动画、姿态、占用和可见性。保留原资源禁用标记过滤，不把每个底层动画片段当作可独立播放的完整动作。

表情：读取全部 EmotionProfilesV4 的 weak、normal、strong。规划器接收可用档位，输出 intensity；完整 expressionSets 留在本地，按原权重选择整套眼睛、闭眼、眉毛、嘴型，不跨组合拼接。关闭眨眼时的返回眼型、TTS 嘴型和不宜常驻的瞬时嘴型保护继续生效。

特效：读取 effectSets 与 fxOnAnimNames，应用原版各档位脸红和泪水。没有原版情绪映射的裸动画不会仅凭编号臆造用途。此实现不声称每个底层特效均提供了独立模型指令。

示例内部控制：[face:shy/strong][action:none]。旧的 [face:shy] 等价于 normal，仍兼容存档。重播保存强度。主对话提示词不注入完整目录，也不增加一次模型请求。

## 验证边界

测试覆盖六套本地资源的三档完整组合、无效权重过滤、规划输出解析、原始台词保留及 TTS 控制标签剥离。资源统计和单元测试不能替代真机视觉验收；需要分别测试害羞、开心、哭泣的弱/强表达及换装后的动作。

原始 JSON、骨骼、贴图仍是本地受保护资源；本次没有上传资源，也没有发布构建。
