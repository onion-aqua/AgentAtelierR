# AgentAtelierR 1.0.0 DX RC1

Android 构建版本：`1.0.0-dx.rc1+30`。预定 GitHub 标签：`v1.0.0-dx-rc1`。

## 本次更新

- 启用苏菲角色切换：人物设定、世界书、对话、记忆、存档和语音配置按角色隔离；当前使用静态立绘，动态资源接口留待后续接入。角色选择器始终显示莱莎和苏菲各自的图标。
- 记忆页增加“马上整理”：整理完成后可在确认卡片中修改最近记忆、长期记忆及其译文，确认后一起保存。
- 持续 ASMR 将“确定主题”和“播放”分开。确定后后台准备稿件与语音；点击底部播放键后进入黑色朗读界面，显示当前文字、译文和语音列表。
- 调整对话控制标签过滤：隐藏思考和工具调用内容，保留 `answer`、`code` 的正文，并减少未闭合标签误吞旁白的情况。

## 构建说明

使用 `tool/build_protected.ps1 -Target apk -Mode release` 进行加密构建。人物资源和构建密钥仅在本地使用，不上传源码仓库。
