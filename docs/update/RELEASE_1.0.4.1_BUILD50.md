# AgentAtelierR 1.0.4.1 更新

## 更新内容

- 新增主对话生图，支持自动识别及手动选择 OpenAI、Gemini、通用同步/异步和 ComfyUI 格式。图片加入聊天历史，并可在虚拟手机的生图管理中查看。
- 优化生图提示词：未指定人物时默认莱莎；只说“生图”时，结合当前存档对话、场景和背景组织画面。
- 更新百炼 Qwen-TTS 配置，增加 Qwen-Audio 3.1/3.0 模型、地域与业务空间、音色、语言及朗读参数，保留旧版 Qwen3 配置。
- 新增应用内更新提示和版本中心，支持资源更新、完整 APK 下载及系统确认安装。
- 新增“海风中的莱莎”手机壁纸，后续可通过资源更新扩充壁纸；默认三张与用户导入壁纸继续保留。

## 使用方法

- 生图：进入“设置 → AI 接口 → 生图接口配置”，填写接口、Key 和模型后，在主聊天发送画图请求；虚拟手机底部最右侧打开生图管理。
- Qwen-TTS：进入“设置 → TTS → 百炼 Qwen-TTS”，按账号地域填写业务空间和 Key，选择匹配的模型、普通/ASMR 音色及目标语言。声音复刻使用可公开读取的参考音频地址，并与合成模型保持一致。
- 更新：启动时可关闭更新提示；也可在“设置 → 关于 → 版本与更新”手动检查。资源准备完成后重新启动生效，代码更新由 Android 系统确认安装。
- 壁纸：打开虚拟手机的壁纸页面选择；新增目录壁纸可本地删除，默认三张不可删除。

## 注意事项

- 旧客户端需先完整覆盖安装一次本次正式 APK，之后才能使用应用内更新。安装前建议备份重要存档。
- 当前代码更新下载完整 APK，尚不支持 APK 差分重建；Windows 自动更新尚未接入。
- 生图、TTS 及复刻可能产生服务商费用；音色、语言和模型权限以账号实际支持为准。新旧 Qwen 模型的音色不能直接通用。
- 聊天备份包含图片消息与缩略图，生图管理中的原图请另外保存。请求超时后不要连续重复提交，以免重复计费。
