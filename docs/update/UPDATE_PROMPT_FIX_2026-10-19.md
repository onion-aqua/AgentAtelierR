# 更新提示修复记录：2026-10-19

## 原因与修复

“没有看到更新”涉及两个问题：测试机仍安装 build 49，使用 `device-test` 渠道，不能发现正式 `stable` 发布；同时，恢复前台的节流检查会覆盖已经取得的更新计划、说明和界面状态，导致更新卡片或提示丢失内容。

设备已覆盖安装正式渠道的受保护 build 51，保留应用数据。运行层改为在节流时保留此前的更新结果、阶段和错误状态，更新说明及已准备的安装包路径也不因没有实际检查而清空。只有收到新的有效检查结果后，才替换对应数据。
